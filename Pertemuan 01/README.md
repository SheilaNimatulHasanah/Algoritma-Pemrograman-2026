## Deskripsi Tugas

Tugas ini membahas penerapan algoritma dan pemrograman pada materi matematika SMA, yaitu barisan dan deret aritmetika. Program dibuat menggunakan bahasa Python untuk menghitung suku ke-n dan jumlah n suku pertama berdasarkan nilai suku pertama, beda, dan banyak suku.

Rumus yang digunakan:

- Suku ke-n: `Un = a + (n - 1) × b`
- Jumlah n suku pertama: `Sn = (n / 2) × (2a + (n - 1) × b)`
